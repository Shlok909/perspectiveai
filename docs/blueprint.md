# **App Name**: Perspective

## Core Features:

- Mentor Input System: Users can search and specify guidance from any person, with the AI validating their existence in the knowledge base and creating profiles dynamically.
- Dynamic Mentor Profile Creation: The AI automatically identifies the specified person, builds a knowledge base by searching their works, extracts key teachings, and identifies communication style.
- Custom Thinking Configuration: Users configure how the mentor should think by providing custom instructions, enabling tailored guidance.
- Intelligent Chat System: Chat interface provides advice in the mentor's style with source citations and confidence levels. By incorporating direct citations of the knowledge used in responses, it functions as a tool aiding in precise and insightful knowledge sharing.
- Multi-Mentor Comparison: Compare insights from multiple mentors.
- Mentor Profiles: Data about each mentor is stored in Firestore to create structured profiles
- Knowledge Base: Data about each mentors background, knowledge domain, quotes is saved in Firestore and indexed

## Style Guidelines:

- Primary color: Deep indigo (#4F46E5) for wisdom and sophistication.
- Background color: Off-white (#F9FAFB) for a clean, distraction-free experience.
- Accent color: Amber (#F59E0B) for insight and to highlight key elements.
- Body and headline font: 'Inter', a sans-serif font for a modern, neutral look, suitable for both headlines and body text.
- Use minimalist icons related to the mentor's field of expertise.
- Clean and intuitive layout with a focus on readability and ease of navigation.
- Subtle animations for loading states and transitions to maintain user engagement without being distracting.
